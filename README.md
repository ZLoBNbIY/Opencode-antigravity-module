# OpenCode Antigravity Module

> **Комплексный модуль интеграции Google Antigravity OAuth для OpenCode**  
> Доступ к моделям **Gemini 3.8 Flash**, **Gemini 3.7 Flash / Pro** и **Claude** через аккаунты Google с поддержкой мульти-аккаунта, умной ротации квот, нативного GUI-менеджера и полным устранением зависаний стриминга («Размышление...»).

## ✨ Возможности модуля

* 🚀 **Прямой доступ к моделям Gemini 3.8 / 3.7**: Используйте новейшие флагманские модели Google без необходимости оформлять платные API-ключи Google Cloud.
* 🔄 **Мульти-аккаунт и автоматическая ротация**: Подключайте неограниченное количество Google аккаунтов. При исчерпании квоты на одном аккаунте плагин автоматически переключается на следующий без прерывания генерации.
* 🧠 **Полная поддержка цепочки рассуждений (Thinking/Reasoning)**: Корректный парсинг и отображение мыслей модели (`thoughtSignature`) в реальном времени.
* 🖥️ **Нативный Desktop GUI Менеджер (Antigravity Hub)**: Удобное графическое приложение на Python (CustomTkinter) для мониторинга остатка квот, смены стратегий, просмотра логов и авторизации.
* 🛠️ **Автономный CLI инструмент**: Управление сессиями и квотами прямо из терминала.

## 🛠️ Устранённые проблемы и баги оригинального плагина

В базовой сборке `@cortexkit/opencode-antigravity-auth` присутствовал ряд критических дефектов, которые полностью исправлены в этом репозитории:

### 1. Зависание на статусе «Размышление...» (Thinking Hang)
* **Причина**: Внутренний движок `@ai-sdk/google` в OpenCode ожидает стрим в формате Server-Sent Events (SSE) с кандидатами на верхнем уровне JSON (`candidates: [...]`). Оригинальный плагин ожидал вложенную структуру (`response: { candidates: [...] }`), из-за чего сбрасывал чанки.
* **Решение**: Функция `transformSseLineWithMetadata` переписана так, чтобы прозрачно поддерживать оба формата ответа Google API.

### 2. Ложная блокировка мягкой квоты (HTTP 412 FAILED_PRECONDITION)
* **Причина**: В плагине по умолчанию было включено правило `"soft_quota_threshold_percent": 20`. Как только пользователь расходовал хотя бы 20% лимита, плагин принудительно возвращал HTTP 412, блокируя диалог задолго до исчерпания реальных лимитов Google.
* **Решение**: Порог мягкой защиты выставлен на `100` (полное отключение блокировки до исчерпания 100% квоты) с автоматическим переключением на запасные аккаунты.

### 3. Зависание CLI в неинтерактивных терминалах
* **Причина**: Функция `isCliAuthorize` блокировала процесс в ожидании TTY stdin, из-за чего скрипты автоматизации и фоновые вызовы зависали навсегда.
* **Решение**: Добавлена проверка `process.stdin.isTTY` и корректное делегирование авторизации.

### 4. Ошибки отмены потока (WebStreams TransformStream)
* **Причина**: При нажатии кнопки «Стоп» в UI OpenCode вызывался метод `.cancel()` стрима, вызывавший необработанные исключения и повреждавший состояние сессии.
* **Решение**: Добавлены безопасные блоки обработки сигналов прерывания стрима.

## ⚡ Быстрый старт

### Способ 1: Автоматическая установка (Windows)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ZLoBNbIY/Opencode-antigravity-module.git
   cd Opencode-antigravity-module
   ```
2. Запустите файл `install.bat` двойным кликом (или из командной строки).  
   Скрипт автоматически:
   * Создаст необходимые каталоги конфигурации (`~/.config/opencode`).
   * Скопирует оптимальные шаблоны настроек.
   * Применит патчи совместимости к кэшу плагина.
   * Установит библиотеки для GUI-менеджера.

### Способ 2: Автоматическая установка (Linux / macOS)

```bash
git clone https://github.com/ZLoBNbIY/Opencode-antigravity-module.git
cd Opencode-antigravity-module
chmod +x install.sh
./install.sh
```

## 🔑 Авторизация Google аккаунтов

Для работы модуля требуется хотя бы один авторизованный аккаунт Google.

### Вариант А: Через консоль (CLI)

Запустите команду входа:
```bash
node plugin/dist/cli.js login
```
В терминале откроется ссылка или запустится браузер:
1. Войдите в свой Google аккаунт.
2. Подтвердите разрешения для Antigravity.
3. Токены автоматически сохранятся в защищённом хранилище:
   * **Windows**: `%USERPROFILE%\.local\share\opencode\auth.json`
   * **Linux/macOS**: `~/.local/share/opencode/auth.json`

Чтобы добавить **второй и последующие аккаунты** для ротации, просто повторите команду `login` в другом профиле браузера.

### Вариант Б: Через GUI Менеджер (Antigravity Hub)

1. Запустите `gui-manager/start_manager.bat`.
2. Перейдите на вкладку **«Управление»** -> нажмите **«Войти в новый аккаунт Google»**.

## ⚙️ Конфигурация OpenCode

Чтобы OpenCode использовал модуль и модели Google Antigravity, убедитесь, что в файле конфигурации OpenCode указан плагин.

Файл конфигурации:
* **Windows**: `%USERPROFILE%\.config\opencode\opencode.json`
* **Linux/macOS**: `~/.config/opencode/opencode.json`

Содержимое `opencode.json`:
```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": [
    "@cortexkit/opencode-antigravity-auth@latest"
  ],
  "provider": {
    "google": {
      "options": {
        "apiKey": "antigravity"
      }
    }
  }
}
```

## 🎛️ Параметры `antigravity.json`

Файл тонкой настройки модуля расположен по адресу:
* **Windows**: `%USERPROFILE%\.config\opencode\antigravity.json`
* **Linux/macOS**: `~/.config/opencode/antigravity.json`

### Рекомендуемая конфигурация:
```json
{
  "$schema": "https://raw.githubusercontent.com/cortexkit/opencode-antigravity-auth/main/schema.json",
  "account_selection_strategy": "hybrid",
  "soft_quota_threshold_percent": 100,
  "switch_on_first_rate_limit": true,
  "quota_style_fallback": true,
  "debug": false
}
```

### Подробное описание настроек:

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `account_selection_strategy` | `string` | `"hybrid"` | Стратегия выбора аккаунта из пула:<br>• `"hybrid"`: комбинация наименьшей нагрузки и максимального остатка квоты.<br>• `"round-robin"`: поочерёдный перебор аккаунтов.<br>• `"least-used"`: выбор аккаунта с минимальным расходом квоты. |
| `soft_quota_threshold_percent` | `number` | `100` | **Критический параметр!** Процент расхода квоты, при котором аккаунт считается исчерпанным.<br>**Важно:** Значение `100` отключает ложные блокировки 412 и использует аккаунт на полную мощность. |
| `switch_on_first_rate_limit` | `boolean` | `true` | Немедленно переключаться на следующий аккаунт при получении ошибки 429 (лимит запросов в минуту), не дожидаясь тайм-аута. |
| `quota_style_fallback` | `boolean` | `true` | Разрешает переключение стилей заголовков авторизации при исчерпании квот основного API. |
| `debug` | `boolean` | `false` | Включает подробное логирование запросов, заголовков и ротации в папку логов. |

## 🖥️ GUI-менеджер: Antigravity Hub

Модуль включает автономное графическое приложение с темной темой для мониторинга состояния аккаунтов.

### Запуск GUI:
* **Windows**: дважды кликните по `gui-manager/start_manager.bat` (или запустите `pythonw gui-manager/antigravity_manager.pyw`).

### Возможности интерфейса:
1. **Вкладка «Аккаунты и квоты»**:
   * Наглядная шкала расхода квот для каждого подключенного аккаунта.
   * Детализация по моделям (`gemini-3.8-flash`, `gemini-3.7-flash`, `claude-3-7-sonnet`).
   * Время до сброса суточных и минутных лимитов.
   * ⏱️ **Автообновление каждые 10 минут**: Фоновый таймер с живым обратным отсчётом в строке состояния (`⏱ Автообновление квот: через 09:59`) автоматически обновляет квоты каждые 10 минут без блокировки интерфейса.
2. **Вкладка «Настройки»**:
   * Интерактивное переключение стратегий ротации и ползунок порога мягкой квоты.
   * Управление автообновлением квот (включение/отключение фонового опроса каждые 10 минут).
3. **Вкладка «Логи и диагностика»**:
   * Просмотр логов запросов и событий ротации в реальном времени.
   * Кнопка очистки зависших сообщений из локальной базы OpenCode.

## 🧪 Тестирование и проверка работоспособности

В папке `scripts/` находятся утилиты для проверки:

### 1. Проверка стриминга и модели Gemini 3.8
```bash
node scripts/test_stream.mjs
```
Скрипт отправит запрос к `antigravity-gemini-3.8-flash` и выведет в консоль пошаговый стриминг, цепочку рассуждений и подтверждение статуса 200 OK.

### 2. Принудительное накатывание патчей
Если вы обновили OpenCode и плагин скачался заново, просто выполните:
```bash
node scripts/patch_plugin.mjs
```
Скрипт автоматически найдет закэшированную версию плагина и применит все фиксы стриминга.

## ❓ Решение проблем (Troubleshooting)

### Q: OpenCode снова завис на «Размышление...»
1. Проверьте параметр `soft_quota_threshold_percent` в `~/.config/opencode/antigravity.json`. Он должен быть равен `100`.
2. Запустите `node scripts/patch_plugin.mjs`, чтобы убедиться, что патчи стриминга применены.
3. Если старый диалог остался зависшим в базе данных, создайте новый диалог (кнопка `+ New Session` в OpenCode).

### Q: Ошибка `412 FAILED_PRECONDITION`
Эта ошибка означает, что все аккаунты исчерпали квоту защиты. Убедитесь, что в `antigravity.json` установлено `"soft_quota_threshold_percent": 100`, либо добавьте ещё один аккаунт Google через `node plugin/dist/cli.js login`.

### Q: Ошибка `429 Too Many Requests`
Google временно ограничил частоту запросов на аккаунте (RPM/TPM). При включенном `"switch_on_first_rate_limit": true` плагин автоматически переключится на другой аккаунт. Если аккаунт один — подождите 30-60 секунд до сброса лимита.
