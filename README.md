# OpenCode Antigravity Module

Интеграция Google Antigravity с OpenCode: модели Gemini и Claude через Google OAuth, управление несколькими аккаунтами и квотами. Включает графический менеджер **Antigravity Hub**. Ветка `V2` предназначена для OpenCode 2.x.

## Установка

### Windows — установка одной командой

Откройте PowerShell и выполните:

```powershell
(irm https://raw.githubusercontent.com/ZLoBNbIY/Opencode-antigravity-module/V2/install.ps1).Trim([char]65279) | iex
```

Установщик загрузит файлы, проверит Node.js (требуется версия 20 или новее), создаст конфигурацию OpenCode и установит компоненты Antigravity Hub. Для GUI также нужен Python 3.10+; если Python отсутствует, его потребуется установить отдельно.

### Windows — из клонированного репозитория

```powershell
git clone -b V2 https://github.com/ZLoBNbIY/Opencode-antigravity-module.git
cd Opencode-antigravity-module
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

### Linux / macOS

```bash
git clone -b V2 https://github.com/ZLoBNbIY/Opencode-antigravity-module.git
cd Opencode-antigravity-module
chmod +x install.sh
./install.sh
```

## Первые шаги

1. Полностью перезапустите OpenCode после установки.
2. Добавьте Google-аккаунт одним из способов:
   - В Hub: запустите `gui-manager/start_manager.bat` (Windows) и выберите добавление Google-аккаунта.
   - В терминале: `node plugin/dist/cli.js login`.
3. В интерфейсе OpenCode (меню выбора моделей / провайдеров):
   - Активируйте ползунок (переключатель) **Google**.
   - Выберите модель с припиской **Antigravity** (например, `google/antigravity-gemini-3.8-flash` или `google/antigravity-claude-sonnet-4-6-thinking`).

> [!NOTE]
> OpenCode запрашивает полный список моделей из API, поэтому в общий перечень могут попадать и уже отключённые со стороны сервиса модели (например, ранние версии Gemini 3.1 / 3.6 / 3.7). Для стабильной работы используйте актуальные флагманские модели с префиксом `antigravity-`.

Чтобы подключить несколько Google-аккаунтов, повторите авторизацию для каждого. Плагин поддерживает ротацию аккаунтов при ограничениях квоты.

## Возможности

- Gemini и Claude через Google Antigravity OAuth.
- Несколько Google-аккаунтов, ротация и отображение квот.
- Antigravity Hub для управления аккаунтами, квотами и настройками.
- Поддержка OAuth-аккаунтов ChatGPT/OpenAI в Hub.
- Бесплатные текстовые модели OpenRouter через ваш API-ключ — отдельный провайдер **OpenRouter Free** в Hub и OpenCode.
- Поддержка шлюза **MWAPI (Cloud Code / CCS)** — подключение моделей Claude (3.7 / 3.5 Sonnet), Gemini и других через личный кабинет `https://api.mwapi.dev/dashboard`, с отображением баланса и расхода прямо в Hub.
- Для DeepSeek используйте доступную бесплатную модель в самом OpenCode. Отдельная интеграция DeepSeek Web в Hub больше не запускается; доступность и квоты определяются сервисом.

Кнопка «Тест» в Hub при необходимости получает свежий Google access token напрямую от CLI через захваченный канал вывода, а не перечитывает старый токен с диска после обновления квот. Для этого GUI и `plugin/dist/cli.js` нужно обновлять вместе. Служебная команда `health-token --email <email>` выводит секретный access token: она предназначена только для канала GUI, её вывод нельзя публиковать или сохранять в логи. Обычные `list` и `quota` токены не выводят. Проверки этого механизма без входа в Google: `npm run test:google`.

Чтобы подключить бесплатные модели OpenRouter:

1. Зарегистрируйтесь или войдите на [openrouter.ai](https://openrouter.ai/).
2. Откройте [страницу API-ключей](https://openrouter.ai/settings/keys) и создайте ключ (**Create API Key**). Создание ключа бесплатно; бесплатные модели доступны в пределах квот OpenRouter.
3. Откройте в Antigravity Hub раздел **OpenRouter Free**, вставьте ключ и нажмите **«Проверить ключ и загрузить модели»**.
4. Отметьте бесплатные модели, которые хотите использовать, и нажмите **«Добавить выбранные в OpenCode»**.

Выбранные модели появятся в отдельном провайдере **OpenRouter Free**. Встроенный провайдер **OpenRouter** отключается, чтобы его общий каталог платных моделей не отображался; при отключении интеграции встроенный провайдер включится снова. Доступность, бесплатные квоты и состав каталога задаёт OpenRouter, и они могут меняться.

> **Важно о бесплатных моделях OpenRouter:** стабильная работа не гарантируется. Из-за особенностей модели или её совместимости с OpenCode возможны ошибки; поддержка изображений и вызова инструментов зависит от модели. При перегрузке провайдеров или исчерпании квот модели могут отвечать медленно либо временно быть недоступны. В таком случае попробуйте позже или выберите другую модель. Для текстовых моделей используйте новый чат без изображений в истории — даже ранее прикреплённая картинка может вызвать ошибку.

## Подключение MWAPI (Cloud Code / CCS)

Если у вас есть подписка или лимит на Cloud Code на сервисе [MWAPI Gateway](https://api.mwapi.dev/dashboard):

1. Откройте панель управления [MWAPI Dashboard](https://api.mwapi.dev/dashboard).
2. Перейдите в раздел токенов ([MWAPI Tokens](https://api.mwapi.dev/token)) и создайте либо скопируйте ваш API-ключ (`sk-...`).
3. Запустите Antigravity Hub и перейдите во вкладку **🌐 MWAPI (Cloud Code)**.
4. Вставьте ваш ключ и нажмите **«Проверить ключ и загрузить модели»**.
5. Hub загрузит список доступных для вашего аккаунта моделей (например, Claude 3.7 / 3.5 Sonnet, Gemini Pro, GPT-4o и др.).
6. Выберите нужные модели и нажмите **«Добавить выбранные в OpenCode»**.

Модели появятся в OpenCode в провайдере **MWAPI (Cloud Code)** (модели с префиксом `mwapi/`). Запросы направляются на `https://api.mwapi.dev/v1` с сохранением ваших лимитов и квот.

### Баланс и расход токенов MWAPI

API-ключ (`sk-...`) не даёт доступа к балансу — MWAPI показывает баланс и расход только через личный кабинет (сессию после входа). Чтобы увидеть их прямо в Hub, не открывая сайт каждый раз:

1. Войдите в [личный кабинет MWAPI](https://api.mwapi.dev/dashboard) в браузере.
2. Откройте DevTools (F12) → вкладку **Network**, выполните вход и найдите запрос `login`; в теле его ответа будет поле `access_token` — скопируйте его значение.
3. В Hub, в разделе **«Баланс и расход токенов»** вкладки MWAPI, вставьте токен и нажмите **«Показать баланс»**.

Hub сохраняет этот токен локально в зашифрованном виде (так же, как API-ключ) и использует его только для чтения баланса. Токен со временем истекает — тогда повторите шаги выше, чтобы получить новый. Кнопка **«Забыть токен»** удаляет сохранённый токен из Hub.

## Требования

- OpenCode 2.x.
- Node.js 20 или новее.
- Python 3.10 или новее — для графического Hub.
- Современный браузер для OAuth-входа.

Установщик Windows проверяет версию Node.js и пытается установить или обновить её, если версия ниже требуемой.

## Конфигурация и данные

Основные конфигурационные файлы находятся в `~/.config/opencode/` (в Windows: `%USERPROFILE%\.config\opencode\`). Обычно установщик создаёт их автоматически. Настройки Antigravity хранятся в `antigravity.json`.

Аккаунты и токены не следует публиковать или добавлять в репозиторий. Для переноса аккаунтов между компьютерами используйте экспорт и импорт в Hub.
