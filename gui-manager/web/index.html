🌐 Сеть, DNS и VLESS

VLESS-туннель

Проверка…

Локальный туннель Xray / sing-box. Выберите VLESS в маршруте нужного провайдера.

Выбранное ядро: проверка…

DNS для маршрутов Hub

● Не проверен

Выберите тип DNS и сервер, затем нажмите «Применить DNS». Используется провайдерами с маршрутом «DNS Hub». Доступность серверов проверяется автоматически раз в минуту.

HTTP(S)-прокси и ротация пула

Прокси проверяются в порядке списка: верхний — основной, ниже — резервные. Перемещайте узлы стрелками. При включённом Failover Hub переходит к следующему прокси, если предыдущий не подключился.

Правила Gemini

Проверяем источники…

Список доменов Gemini и Google AI. Hub сверяет адрес подключения с правилами и применяет выбранный маршрут Google; это не проверка доступности аккаунта или модели.

Выбор маршрута

Маршрут каждого провайдера настраивается справа от аккаунтов и лимитов в его вкладке.

Авто → … — сравнивает настроенные маршруты, выбирает самый доступный и быстрый для этого провайдера и переключается при ошибке подключения. Ручной выбор закрепляет один маршрут.

Auto перепроверяет маршруты раз в минуту; при отказе выбранного пробует другой доступный. Активная генерация не переотправляется. Индикаторы доменов показывают TCP-соединение, а не доступность конкретной модели.

Провайдеры

Отключённый провайдер скрывается в Hub и из выбора моделей OpenCode. Аккаунты и ключи сохраняются. Нажмите «Сохранить настройки», чтобы применить изменения.

Стратегия выбора аккаунтов
⭐ Рекомендуется: сохраняет контекст сессии на одном аккаунте, но плавно ротирует при исчерпании лимитов.
Переключение при Rate Limit (429)
Поведение при закрытии окна
Резервное копирование и перенос на другой ПК
