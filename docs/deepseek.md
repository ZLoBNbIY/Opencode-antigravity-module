# DeepSeek Web: прямые запросы к веб-чату

> Архивная инструкция. Отдельный раздел DeepSeek Web удалён из Hub и больше не запускается. Для DeepSeek используйте доступную бесплатную модель в OpenCode. Старые локальные данные и настройки автоматически не удаляются.

Hub подключается именно к `chat.deepseek.com`, не к платному Platform API и не
к DeepSeek Harness. Браузер Chromium нужен только для разового входа: Hub
считывает веб-сессию, шифрует её через DPAPI CurrentUser, закрывает браузер и
после этого общается с сайтом напрямую по HTTPS из Python stdlib.

## Использование

1. Полностью закройте Hub через трей и запустите обновлённый Hub.
2. **DeepSeek (Web) → Войти в DeepSeek Web**. Выберите системный Chromium-браузер
   (например, Яндекс) или Chrome/Edge.
3. В отдельном профиле войдите на `chat.deepseek.com` и пройдите проверку сайта.
   После обнаружения входа Hub сохранит защищённую сессию и закроет окно.
4. В OpenCode выберите `deepseek-web/deepseek-chat` (Instant) или
   `deepseek-web/deepseek-expert` (Expert).

Дальше браузер не нужен и запросы через него не идут. При истечении веб-сессии
нужно повторить разовый вход. Сам сайт всё равно сохраняет запросы как чаты в
истории аккаунта: это веб-чат, а не отдельный API-продукт.

## Схема

```text
Разовый вход: Hub → отдельный браузер → пользователь входит на chat.deepseek.com
Запросы: OpenCode → защищённый loopback Hub → HTTPS Python-клиент → chat.deepseek.com
```

HTTP-клиент создаёт чат-сессию, запрашивает PoW challenge, решает
DeepSeekHashV1 на чистом Python и отправляет completion с `X-DS-PoW-Response`.
WASM, Playwright, дополнительные Python-пакеты и загрузка компонентов не нужны.
PoW в чистом Python может занять десятки секунд при высокой сложности; запросы
выполняются последовательно и отмена проверяется во время вычисления.

На Windows токен и cookies веб-чата хранятся только в
`web-session.json`, зашифрованном DPAPI CurrentUser; в конфиг OpenCode они не
попадают. На Unix файл хранится с правами `0600`. Ключ локального loopback-канала
также защищён. Redirect на другой хост блокируется. Логи не содержат токены,
cookies, prompt или текст ответа.

## Ограничения

- Внутренний протокол веб-чата неофициальный и может измениться; DeepSeek может
  ограничить автоматические запросы или потребовать повторного входа.
- PoW-алгоритм реализован по опубликованному reverse-engineering описанию и
  требует проверки на актуальном challenge сайта. Сам факт работы локальных
  тестов не подтверждает реальную генерацию.
- Каждый вызов создаёт запись чата на стороне DeepSeek. Контекст запроса,
  включая файлы и результаты инструментов, отправляется сервису.
- Скрытые system/developer инструкции OpenCode исключены из текста запроса.
  Tool calling эмулируется текстовым JSON и может быть менее надёжным, чем API.
- Поддерживается только текст; DeepThink/поиск отключены. Учитываются лимиты
  веб-чата, а не платный Platform API.

## Данные и переход

Каталог: `~/.local/share/antigravity-hub/deepseek/`.

| Файл | Назначение |
| --- | --- |
| `browser-profiles/<браузер>/` | Отдельный профиль только для разового входа; сохраняется |
| `web-session.json` | DPAPI-защищённая сессия для прямых HTTPS-запросов |
| `web-state.json` | Разрешение подключения и выбранный браузер |
| `web-channel.json` | Временный ключ loopback-канала; удаляется при закрытии Hub |
| `browser-plugin/` | Локальный плагин OpenCode V2 |
| `logs/web.log` | Безопасные коды состояния без пользовательского содержимого |

После обновления с прежней browser-proxy версии потребуется один раз войти
заново, чтобы создать защищённый `web-session.json`. Старые account/Harness
файлы, профиль браузера и другие старые данные не удаляются. Кнопка **Отключить**
удаляет только новую защищённую web-сессию и отключает модели; профиль и прежние
данные остаются.

## Проверки

```powershell
python -m unittest discover -s tests -p "test_deepseek*.py" -v
node --test tests/deepseek-plugin.test.mjs
```

Офлайн-тесты покрывают PoW, защищённое хранение, формирование HTTPS-запросов и
разбор SSE. Они не заменяют проверку реального входа, PoW challenge и генерации
на текущем `chat.deepseek.com`; реальный inference-тест расходует веб-лимит.
