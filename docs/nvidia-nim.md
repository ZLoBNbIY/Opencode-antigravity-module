# NVIDIA NIM в Antigravity Hub

1. Откройте **NVIDIA NIM** в боковом меню Hub и вставьте API-ключ `nvapi-…` с [build.nvidia.com](https://build.nvidia.com/).
2. Каталог загружается автоматически при запуске Hub и при открытии вкладки NVIDIA NIM (если ключ уже сохранён). Кнопка **Загрузить модели** служит для принудительного обновления. Список NVIDIA может открываться без действующего ключа и не гарантирует, что каждая модель доступна вашему аккаунту. Hub показывает только чат-модели hosted NIM API (каталог личного кабинета шире: туда входят embedding/rerank/safety-модели и контейнеры для собственного развёртывания).
3. Каталог отображается карточками: у каждой модели есть значок вендора, полный ID и короткое имя. Отметьте нужные карточки и нажмите **Добавить выбранные в OpenCode**. Для проверки доступа отметьте одну модель и нажмите **Проверить генерацию выбранной модели** — тест может расходовать квоту.
4. После подключения в заголовке вкладки, в боковом меню и на дашборде появляется индикатор «Подключён». Статус считается подключённым, когда сохранён ключ и хотя бы одна модель добавлена в OpenCode.
5. Выберите модель из раздела **NVIDIA NIM** в OpenCode Desktop. Модель по умолчанию Hub не меняет.

## Сетевая маршрутизация

NVIDIA NIM использует тот же механизм маршрутизации, что ChatGPT:

- запросы каталога (`GET /v1/models`), проверки генерации и запросы OpenCode идут через локальный диспетчер Hub `127.0.0.1:10880`;
- в правой панели вкладки NVIDIA NIM доступны режимы **Auto**, **DNS Hub**, **VLESS**, **Внешний прокси** и **Напрямую**, сравнение маршрутов и диагностика домена `integrate.api.nvidia.com`;
- при добавлении или отключении моделей Hub автоматически синхронизирует настройки маршрута в конфиге OpenCode;
- отправка ключа не зависит от выбранного маршрута — ключ передаётся только в заголовке `Authorization` конечному API.

При стандартной конфигурации копии Hub, запущенные от одного пользователя, используют общий каталог данных Hub и общий конфиг OpenCode. Достаточно подключить NVIDIA в одной копии. Кнопка **Отключить** удаляет общее подключение.

Ключ хранится в отдельном локальном файле `opencode-secrets/nvidia-nim.key` в каталоге данных Hub. Он не зашифрован: конфиг OpenCode ссылается на файл через `{file:…}`, чтобы Desktop мог работать без CLI и без запущенного Hub. Не публикуйте и не копируйте этот файл в общедоступные папки.
